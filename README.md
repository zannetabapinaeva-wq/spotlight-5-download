# Spotlight 5 — английский язык

**[Открыть приложение в браузере](https://zannetabapinaeva-wq.github.io/spotlight-5-download/)**

Одна общедоступная ссылка для компьютера, телефона и планшета. Установка и вход в GitHub не требуются. На компьютере доступны боковое меню и широкая сетка карточек; на телефоне интерфейс адаптируется к экрану.

В приложении — 100 учебных разделов, 407 слов с индивидуальными иллюстрациями, переводами и озвучкой, интерактивные задания, отдельные профили и сохранение прогресса. Имя, избранное и учебные результаты хранятся в браузере конкретного устройства и автоматически между устройствами не синхронизируются. Для озвучки используется поддержка синтеза речи браузера и английский голос устройства.
